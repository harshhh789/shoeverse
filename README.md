# Shoeverse 👟  
A modern Nike-inspired responsive footwear website built using **HTML & CSS**.  
This project showcases a clean UI design similar to an e-commerce shoe store with product listings, a hero section, and user interaction elements.

---

(You can add a deployed link later)

## 📌 Features

- Modern and clean UI with gradient theme  
- Nike-inspired landing hero section  
- Product slider and product showcase  
- Add to cart buttons (UI mock)  
- Social media sidebar links  
- Hover effects with smooth visuals  
- Responsive layout (mobile friendly with improvements planned)
